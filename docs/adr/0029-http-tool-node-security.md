# ADR-0029: HTTP 도구 노드 보안 — 도메인 허용 목록, 해석 뒤 IP 차단, 비밀 참조

## Status
Accepted (2026-10-24, 사용자 결정)

## Context
HTTP 도구 노드는 테넌트가 그린 흐름에서 서버가 외부 URL을 부르는 기능이다. 공개 위젯·`/try`의 방문자 입력이
URL·헤더·본문에 섞일 수 있어 SSRF(사설망·메타데이터 엔드포인트 접근), DNS 리바인딩, 리다이렉트 우회, 느린·큰 응답으로
워커를 묶는 공격, 비밀 키 유출이 모두 열린다. 운영 박스는 컨테이너 55개가 있는 공용 Oracle 박스라 내부망 노출이 특히 위험하다.

## Decision
- **도메인 허용 목록**: 테넌트가 등록한 **HTTPS 도메인**만 부른다(정확한 호스트 일치, 와일드카드는 명시적으로 등록한 하위 도메인 형태만).
  `http://`, IP 리터럴 호스트, 사용자 정보(`user@host`), 기본 외 포트는 거부한다.
- **해석 뒤 IP 차단**: 호스트를 DNS로 해석한 **모든** 주소를 검사해 사설(RFC 1918, ULA `fc00::/7`), 루프백, 링크로컬
  (`169.254.0.0/16`, `fe80::/10`), 메타데이터(`169.254.169.254`, `fd00:ec2::254` 등), 미지정·브로드캐스트·멀티캐스트·CGNAT
  (`100.64.0.0/10`), IPv4 매핑 IPv6를 거부한다. **검사한 그 IP로 연결**한다(해석과 연결 사이 리바인딩 차단, SNI·Host는 원래 호스트).
- **리다이렉트마다 다시 검사**: 자동 따라가기를 끄고, 각 `Location`을 허용 목록·스킴·해석 IP 검사에 다시 통과시킨다. 최대 횟수를 둔다.
- **자원 상한**: 전체 시간 **5초**(연결·읽기 포함), 응답 본문 **256KB**까지(스트리밍으로 읽다가 넘으면 끊고 실패).
- **비밀**: 테넌트 비밀(API 키 등)은 암호화해 저장한다(기존 Fernet 방식). 흐름 JSON에는 `{{secret.이름}}` **참조만** 둔다.
  치환은 요청을 만들 때 서버에서만 한다. 판단 기록·로그·오류 메시지에서는 비밀 값을 가린다(원문과 일치하는 부분 문자열 포함).
- **`/try`에서는** 실제 외부 호출 대신 예제용 가짜 API만 부른다.
- **보안 시험을 먼저 쓴다**: 위 규칙마다 실패하는 시험(사설 IP로 해석되는 도메인, 리다이렉트로 메타데이터, 시간 초과, 크기 초과,
  기록에 비밀 노출)을 먼저 만들고 구현한다. 외부 DNS·서버는 시험 안의 결정적 대역(로컬 리졸버 주입, 로컬 HTTPS 서버)으로 둔다.

## Considered Options
- **차단 목록만(허용 목록 없음)**: 기각. 차단 범위를 하나 놓치면 바로 SSRF다.
- **송신 프록시(Smokescreen 등) 컨테이너**: 보류. 박스 메모리가 빠듯하다. 애플리케이션 계층 검사로 시작하고, 필요해지면 앞에 둔다.
- **흐름 JSON에 비밀을 암호문으로 박기**: 기각. 버전이 바뀌지 않아 키 회전 때 모든 버전을 다시 써야 한다.

## Consequences
- HTTP 클라이언트는 「해석 → 검사 → 그 IP로 연결」을 하는 전용 계층으로 감싼다(일반 `httpx` 호출 금지). sandcorp-auth의 CIMD 가져오기(#20)와 같은 방식이다.
- 테넌트 설정에 「허용 도메인」과 「비밀」 화면이 생긴다(비밀은 쓰기 전용, 조회 시 이름만).
